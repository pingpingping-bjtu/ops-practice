  
## 一、常用命令  
  
1. `cd`（change directory）：切换到指定目录
```bash
#切换到/home目录
cd 
cd ~
#切换到上级目录
cd ..
#切换到上上级目录
cd ../..
```
 2. `df`(disk free): 显示磁盘空间使用情况
	-a：显示所有文件系统
	-h：以人类可读形式显示
	-T：显示文件系统类型
```bash
df -h
Filesystem Size Used Avail Use% Mounted on 
/dev/sda6 29G    4.2G 23G 16% / 
udev      1.5G   4.0K 1.5G 1% /dev 
tmpfs     604M   892K 603M 1% /run 
none      5.0M   0    5.0M 0% /run/lock 
none      1.5G   156K 1.5G 1% /run/shm
```
 - Filesystem：文件系统的名称或标识符。
 - Size：文件系统的总容量，以 1KB 块为单位。即文件系统总大小。
 - Used：文件系统已经使用的容量，以 1KB 块为单位。
 - Avail：文件系统中仍然可用的容量，以 1KB 块为单位。
 - Use%：文件系统已使用容量占总容量的百分比。 
 - Mounted on：文件系统被挂载到的目录或位置。
3. `du`(disk usage):显示目录或文件占用空间
-a：显示指定文件夹的目录结构
-h：人类可读
-s：总结目录总大小
-mh：强制MB大小显示
-exclude="x.log"：排除指定文件的影响
-time ：显示时间
```bash
[root@centos8 ~]# du -a a
0	a/b/c/d/e
0	a/b/c/d
0	a/b/c
0	a/b
4	a/a.txt
4	a

```
